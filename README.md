
# R4MarineScience

<!-- badges: start -->
<!-- badges: end -->

The goal of R4MarineScience is to understand how to use R for marine science 
data analysis. The repository contains a series of R scripts and Quarto 
documents that demonstrate various data manipulation, visualization, and 
analysis techniques relevant to marine science research.
## Structure

- `data/` - raw, unedited source files (read-only)
- `code/` - R scripts, run in order
- `outputs/` - cleaned data tables and figures
- `docs/` - Quarto (.qmd) documents and related files
